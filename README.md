# OliPath

### Show it. Hear it. Understand it. Do it.

OliPath is an AI-powered accessibility assistant designed to help first-time digital users understand government services and digital forms through simple text, voice, and visual guidance.

## Features

- Voice and text interaction
- Regional language support
- AI-powered visual understanding
- Point & Explain
- Make It Simpler
- Step-by-step guided navigation
- Beginner-friendly interface

## Tech Stack

- Google Gemini AI
- TypeScript
- Vite
- React
- Web Speech API
